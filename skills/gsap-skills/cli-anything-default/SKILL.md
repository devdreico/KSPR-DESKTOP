# Capability Layer — Guide for KSPR I

Use `/capabilities` to discover installed tools, `/capabilities info <id>` to inspect them and `/capabilities run <id> --key=value` only after checking permissions. Never guess capability IDs. Prefer structured JSON output and verify exit code and stderr.
